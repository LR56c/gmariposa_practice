# angular_app

Panel de Órdenes. Angular 22.2 (standalone, zoneless, TypeScript 6.0 `strict`), runner de pruebas Vitest, Node 24.

```bash
cd angular_app
npm install
ng serve      # http://localhost:4200
ng test
ng build
```

Si no tienes el CLI global, usa `npx ng <comando>`.

## Extras incluidos

- Validación y errores con `effect` (`Schema` y `Result`).
- i18n es/en con `@angular/localize`.
- Modo oscuro.
- Tailwind sobre tokens de diseño.
- Demo en GitHub Pages.
